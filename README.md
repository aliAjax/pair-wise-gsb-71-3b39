# 视觉回归基线审批与差异定位平台

基于 Vue 3 的本地可运行前端工程，用于管理截图回归运行、差异定位、忽略规则和基线审批。数据由 Axios 模拟适配器提供，并持久化到浏览器 `localStorage`。

## 技术栈

- Vue 3 + TypeScript + Vite
- Arco Design Vue
- Pinia
- Vue Router
- TanStack Query for Vue
- Axios

## 启动

```bash
npm install
npm run dev
```

默认开发地址为 `http://localhost:18471`。

## 构建

```bash
npm run build
npm run preview
```

## 工作区

- 运行概览：发布阻断项、差异趋势和最近运行
- 回归运行：按项目、页面、设备、主题、构建和状态筛选，合并重复运行
- 差异定位：基线/当前图并排、区域缩放、严重级筛选、区域忽略（随运行持久化）和审批
- 审批队列：批量合并、风险排序、规则失效触发的待复核队列和审批入口
- 历史基线：版本、批准人、原因、关联运行、批准时忽略规则快照，以及生效 / 已取代 / 已失效待复核三态
- 忽略规则：动态区域选择器、作用范围、最大色差、版本号和启用控制
- 结果导出：导出包含运行、差异、版本和审批证据的 CSV

## 审批与基线一致性

- 评审页展示运行版本号；审批与区域忽略均带乐观锁版本。两个标签页同时提交同一运行时，后到的旧版本提交返回 409 失败，运行保留在待审/待复核队列，不覆盖先到的结论。
- 批准时固化当前生效的忽略规则快照与忽略区域证据并生成新基线；同一项目 + 页面 + 设备 + 主题始终只有一条生效基线，旧版本转为「已被取代」。
- 忽略规则停用、修改或删除后，引用该规则快照的有效基线立即标记为「已失效待复核」，关联已批准运行回到复核队列；历史基线、规则快照与历次审批依据照旧可查。
- 旧版本 `localStorage` 数据在首次读取时自动迁移（补版本号、规则快照与状态字段），不影响既有记录查看。

浏览器首次打开时会自动写入示例数据。审批或规则调整会写入 `visual-regression-platform-v1` 对应的本地存储键。
